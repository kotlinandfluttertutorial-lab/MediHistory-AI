# Skill: Prescription OCR Review
1. Preserve the original image/PDF and metadata.
2. Extract typed fields with confidence and source page/region where available.
3. Never guess missing values.
4. Flag illegible, conflicting, or low-confidence names/strengths for patient review.
5. Keep raw OCR separate from normalized medicine entities.
6. Record user corrections and review status.
7. Link each medicine to its source.
8. Test handwritten, printed, rotated, blurred, low-light, multi-page, and obscured documents.
9. Never automatically change a medication plan from OCR.
Suggested fields: raw medicine name, candidate ingredient, brand, strength, dosage text, route, frequency, duration, confidence, review status, source reference.
