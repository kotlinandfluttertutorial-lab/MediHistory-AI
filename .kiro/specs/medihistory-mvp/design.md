# MVP UX Design
## Destinations
Home; My Records; Medication History; Review Prescription; Duplicate Review; New Doctor Mode; Privacy & Backup.
## UX rules
Material 3 Android-native design. Mark data as AI-extracted, patient-confirmed, or unresolved. Every medicine has “View prescription.” Do not use color alone. Separate current/past/unknown medicines. Unreviewed data uses neutral styling; potential issues use clear warning styling.
## New Doctor Mode report
Generated date; patient-entered profile; allergies/conditions with confirmation status; current, past, unknown medicines; potential duplicate findings and sources; selected tests/documents; source index and OCR limitation note.
