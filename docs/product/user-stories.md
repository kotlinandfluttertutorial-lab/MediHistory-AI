# User Stories
1. Scan/import prescriptions and keep them together.
2. Review/correct extracted medicine details.
3. See medicines from different doctors with source, date, strength, and status.
4. See potential duplicate ingredients with evidence and original sources.
5. Create a New Doctor Mode report from selected records.
6. View locally saved records offline.
7. Opt into encrypted cloud backup and see sync status.
8. Preview and share selected records intentionally.
9. Export/delete records and understand backup retention.
10. Distinguish AI-extracted, patient-confirmed, and unresolved data.
