- **Summary:** Medicine-prescription source link — navigation
- **Description:** Implement the source document link composable used in the medicine explorer and medicine detail screens. ## Required Tests
### Integration Tests
- Tapping a source link on a medicine item navigates to the correct prescription detail screen.

### Negative Tests
- Tapping a source link for a deleted prescription shows a plain-language "Prescription removed" message and does not crash.

### Accessibility Tests
- Source link has a content description that includes the prescription date (e.g. "View prescription from [date]").
- Touch target is ≥ 48×48 dp.
