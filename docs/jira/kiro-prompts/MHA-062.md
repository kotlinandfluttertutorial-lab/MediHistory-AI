# MHA-062 — Dose logging — taken, skipped, and missed

## Jira Ticket
- **ID:** MHA-062
- **Epic ID:** MHA-E09
- **Epic Name:** Reminders and Adherence
- **Summary:** Dose logging — taken, skipped, and missed
- **Description:** Implement the dose log entry UI: from the notification action or the reminder list, patient can log a dose as Taken, Skipped, or Missed. Log entry is created with status, loggedTime, and patientReported = true. Adherence summary per medicine shows counts of Taken/Skipped/Missed in the last 7 days.

## Implementation Boundaries (what NOT to do)
- Do not implement the reminders list screen — that is MHA-063.
- Dose log data must NOT be passed to the history summariser as "documented" data — it is always patient-reported.
- Do not auto-assign medicine status based on dose log data.
- Do not add diagnosis, prescribing logic, dose optimisation, or auto-medication changes.
- Do not bypass the repository pattern or call Room directly from UI.
- Do not hardcode credentials or API keys.
- Do not use real patient data in tests; use synthetic fixtures only.
