# MHA-073 — Consent management UI

## Jira Ticket
- **ID:** MHA-073
- **Epic ID:** MHA-E11
- **Epic Name:** Security, Privacy, and Data Management
- **Summary:** Consent management UI
- **Description:** Implement the consent management screen: shows all consent items (data storage, cloud backup, sharing), their current status (granted/not granted), the date consent was granted, and a revoke option. Revoking cloud backup consent disables backup and explains retention. Consent records are stored in the local database (not transmitted).

## Implementation Boundaries (what NOT to do)
- Do not transmit consent records to the backend.
- Do not pre-grant consent on the user's behalf; all consent is explicit.
- Do not implement cloud backup logic here — that is MHA-072.
- Do not bypass the repository pattern or call Room directly from UI.
- Do not hardcode credentials or API keys.
- Do not use real patient data in tests; use synthetic fixtures only.
