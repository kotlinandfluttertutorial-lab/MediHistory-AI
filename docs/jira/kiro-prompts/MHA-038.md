# MHA-038 — Medicine status assignment — Current, Past, Unknown

## Jira Ticket
- **ID:** MHA-038
- **Epic ID:** MHA-E05
- **Epic Name:** OCR Processing and Review
- **Summary:** Medicine status assignment — Current, Past, Unknown
- **Description:** Implement the UI for patients to assign medicine status (Current/Past/Unknown) from the medicine detail screen. Status is patient-assigned and stored on the Medicine entity. Changing status updates the medicine explorer grouping immediately. Status is never auto-assigned by the system.

- Do not allow the system to auto-assign or auto-change status — all status changes must be explicit patient actions.
- Do not add diagnosis, prescribing logic, dose optimization, or auto-medication changes.
- Do not modify the Medicine Room entity definition — that is MHA-034.
- Do not hardcode navigation route strings; use the Routes object.
- Do not bypass the repository pattern or call Room directly from UI.
- Do not hardcode credentials or API keys.
- Do not refactor unrelated screens.

## Required Tests
### UI Tests
- Change status from UNKNOWN to CURRENT: verify the medicine moves to the Current section in the explorer.

### Unit Tests
- New medicines default to UNKNOWN status.
- Status update action writes the new status to the Medicine entity via the repository.

### Negative Tests
- No system logic in the app changes status automatically when a prescription is added or OCR completes.
