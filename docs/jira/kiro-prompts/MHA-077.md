## Required Tests
### UI Tests (Compose / Espresso):
1. Add prescription via camera: mock CameraX → confirmation → file saved in app-private storage.
2. Add prescription via file picker: import synthetic JPEG → file saved.
3. OCR review: confirm a field (sets REVIEWED), edit a field (patientValue set, rawValue unchanged), reject a field (sets REJECTED).
4. Mark duplicate alert as reviewed: tap Mark as Reviewed → badge updates to Reviewed.
5. Generate and view medical history: trigger generation → history detail screen shows sections with type labels.
- Cancel at OCR review does not save changes.
- AccessibilityChecks enabled in BaseComposeTest.
