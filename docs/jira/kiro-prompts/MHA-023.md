## Required Tests
### Unit Tests
- CRUD operations on in-memory database (insert, update, delete, getById).
- `listByPatient` returns only prescriptions for the given `patientId` (patient-scoped query).
- Cascade delete: deleting a Prescription removes associated PrescriptionMedicine rows.
- `documentHashSha256` is non-null after insert.
- OcrStatus enum has all five values: PENDING, PROCESSING, NEEDS_REVIEW, REVIEWED, ERROR.

### Security Tests
- `listByPatient` with a different `patientId` returns an empty list (cross-patient isolation).

### Negative Tests
- Insert with missing required fields fails validation.
