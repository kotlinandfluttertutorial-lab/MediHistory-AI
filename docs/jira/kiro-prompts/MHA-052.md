## Implementation Boundaries (what NOT to do)
- Do not implement the backend history API — that is MHA-053.
- Do not implement the history confidence display — that is MHA-051.
- PENDING_REVIEW records must always be excluded from generation — never include unreviewed data.
- Confirmed summary must be saved as a new version, not overwriting an existing one.
- Do not add diagnosis, prescribing logic, dose optimisation, or auto-medication changes.
- Do not bypass the repository pattern or call Room directly from UI.
- Do not hardcode credentials or API keys.
- Do not use real patient data in tests; use synthetic fixtures only.

## Required Tests
### Integration Tests
- Generate with one unreviewed record: verify it appears in the exclusion list.
- Cancel from exclusion list does not save a new version.
- Confirmed generation increments the version.
