# MHA-051 — History source confidence display

## Jira Ticket
- **ID:** MHA-051
- **Epic ID:** MHA-E07
- **Epic Name:** Medical History
- **Summary:** History source confidence display
- **Description:** Implement confidence display for uncertain sections in the history detail screen. UNCERTAIN sections show a visual indicator (e.g. amber badge) and a tooltip or footnote explaining what uncertain means. Low-confidence source fields are listed in an expandable detail panel within the section.

- Do not implement the backend history API — that is MHA-053.

- The explanation text must be: "This information was extracted with low confidence and has not been fully verified."
- Do not add diagnosis, prescribing logic, dose optimisation, or auto-medication changes.
