## Implementation Boundaries (what NOT to do)
- Do not cascade-delete prescriptions when a doctor is deleted.
- Prescriptions with a deleted `doctorId` must display "Doctor removed" — do not crash.
- `DoctorPickerComponent` must show only doctors for the current patient — never another patient's doctors.
- Do not implement features beyond this ticket's scope.
- Do not bypass the repository pattern or call Room/API directly from UI.
- Do not add clinical advice, diagnoses, or treatment recommendations.
- Do not hardcode credentials or API keys.

## Required Tests
### Unit Tests
- Verify prescription entity has a nullable `doctorId` foreign key.
- Verify deleting a doctor does not cascade-delete linked prescriptions.

### Integration Tests
- Delete a doctor, open a linked prescription, verify "Doctor removed" label appears.

### UI Tests (if applicable)
- UI: `DoctorPickerComponent` shows correct doctor list for the current patient.

### Security Tests (if applicable)
- Verify `DoctorPickerComponent` cannot display doctors from a different patient.
