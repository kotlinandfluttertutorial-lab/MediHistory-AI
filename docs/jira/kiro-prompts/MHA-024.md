### UI Tests
- List renders 10 prescriptions without layout issues.
- Empty state shows a call-to-action when the list is empty.
- Tapping an item navigates to the prescription detail screen (correct route).
- StatusBadge content description is announced by TalkBack.

- Each list item has a minimum 48×48 dp touch target.
