## Implementation Boundaries (what NOT to do)
- Do not use real external services (OcrService, HistoryGenerationService) in tests — use mocks.
- Do not use real patient data in fixtures.
- Do not add new API endpoints; test what already exists.
- Do not fabricate test output; run actual tests and report real results.

## Required Tests (per endpoint group):
### Prescriptions:
- Authenticated CRUD (create, list, detail, update, delete) — all succeed.
- Unauthenticated request → 401.
- Cross-patient access → 404 (not 403).
- Invalid body → 422.

### Medicines:
- Authenticated list and detail — correct patient data returned.
- Cross-patient → 404. Unauthenticated → 401.

### Alerts:
- Authenticated list, detail, review, unreview.
- Cross-patient → 404. Unauthenticated → 401.
- Review on already-reviewed alert is idempotent.

### History:
- Generate (POST → 202), list, detail.
- Cross-patient → 404. Unauthenticated → 401.

### Share events:
- Create and list — no document content in response.
- Cross-patient → 404.

### Auth:
- Valid credentials → JWT returned.
- Invalid credentials → 401.
- Expired token → 401 on subsequent request.
