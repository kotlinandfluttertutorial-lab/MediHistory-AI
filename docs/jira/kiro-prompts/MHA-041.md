# MHA-041 — Duplicate detection algorithm — normalised active ingredient matching

## Jira Ticket
- **ID:** MHA-041
- **Epic ID:** MHA-E06
- **Epic Name:** Medication History
- **Summary:** Duplicate detection algorithm — normalised active ingredient matching
- **Description:** Implement the deterministic DuplicateDetector service (no AI inference). Algorithm: normalise active ingredient strings (lowercase, remove punctuation, resolve synonyms from a local synonym table), find pairs of REVIEWED PrescriptionMedicine records with matching normalised active ingredients for the same patient, exclude self-matches (same prescription). Output: list of DuplicatePair records.
