## Required Tests
### Unit Tests
- `isValidDate`: returns false for malformed strings, true for valid ISO 8601 dates.
- `isAllowedFileExtension`: returns true for jpg, jpeg, png, pdf; false for docx, xls.
- `isValidConfidence`: returns false for < 0.0 and > 1.0, true for 0.0 and 1.0 (boundary values).
- `isValidReviewStateTransition`: allows PENDING_REVIEW → REVIEWED, PENDING_REVIEW → REJECTED; rejects all other transitions.
- 100% branch coverage for all functions.
