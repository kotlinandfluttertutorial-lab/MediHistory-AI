## Required Tests
### Integration Tests
- Capture flow: capture image, confirm, verify file exists in app-private storage with SHA-256 hash match.
- Retake: verify the temp file is discarded and no orphan files remain.

### Security Tests
- File permission is MODE_PRIVATE (not accessible to other apps).
- No file is written to shared external storage.

### Negative Tests
- App does not crash when camera permission is denied; shows permission rationale screen.
- Retake does not leave temp files on disk.
