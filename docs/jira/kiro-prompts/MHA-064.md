# MHA-064 — Interaction check service interface and provider configuration

## Jira Ticket
- **ID:** MHA-064
- **Epic ID:** MHA-E10
- **Epic Name:** Interaction Checking
- **Summary:** Interaction check service interface and provider configuration
- **Description:** Define the InteractionCheckService interface (check(medicineIds: List): InteractionCheckResult). InteractionCheckResult: available boolean, interactions list, unavailableReason nullable. Provider is configured via MED_REFERENCE_PROVIDER env variable. When the variable is empty or unset, the service returns available = false with the required unavailable message.
