## Implementation Boundaries (what NOT to do)
- Do not implement duplicate alert endpoints — that is MHA-047.
- Do not implement medicine normalization or active ingredient matching — that is a separate concern.
- Do not return 403 for cross-patient access — return 404 to avoid leaking resource existence.
- Do not log medicine names, prescription text, or document contents.
- Do not add diagnosis, prescribing logic, dose optimization, or auto-medication changes.
- Do not commit real credentials or API keys.
- Do not refactor unrelated routers.

## Required Tests
### Positive Tests
- GET /medicines returns correct medicines for the authenticated patient.
- Search param `q` filters by name and ingredient.
- Pagination params `page` and `page_size` work correctly.

### Security Tests
- Cross-patient access returns 404.
- Unauthenticated request returns 401.

### Negative Tests
- Invalid `page_size` value returns 422.
