# MHA-046 — Combination medicine handling in duplicate detection

## Jira Ticket
- **ID:** MHA-046
- **Epic ID:** MHA-E06
- **Epic Name:** Medication History
- **Summary:** Combination medicine handling in duplicate detection
- **Description:** Extend the DuplicateDetector to handle combination products: when a medicine has multiple active ingredients (e.g. A+B), match each constituent against single-ingredient medicines. Generate a reduced-confidence DuplicateAlert for partial matches. Alert content notes which ingredient matched and that a combination product is involved.
