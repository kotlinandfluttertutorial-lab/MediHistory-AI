## Required Tests
### Integration Tests — full prescription lifecycle:
1. Create a synthetic patient and log in.
2. Create a prescription (POST /prescriptions → 201).
3. Trigger OCR (mocked OcrService returns synthetic fields) → prescription status → NEEDS_REVIEW.
4. Review fields (PATCH review state → REVIEWED).
5. Verify alert generated (GET /alerts returns one alert for the reviewed pair).
6. Trigger history generation (POST /history/generate → 202) with mocked HistoryGenerationService.
7. Verify history detail contains source references pointing to the prescription.
8. Negative: history generation with an unreviewed record excludes that record from the summary.
9. Security: audit log created at share and export steps.
