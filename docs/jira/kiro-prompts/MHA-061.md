## Implementation Boundaries (what NOT to do)
- Do not implement the dose logging UI — that is MHA-062.
- Do not implement the reminders list screen — that is MHA-063.
- Notification text must include the medicine name and prescription date as specified; never include other prescription details.
- A disabled reminder must have its WorkManager job cancelled — it must not fire.
- Do not add diagnosis, prescribing logic, dose optimisation, or auto-medication changes.
- Do not hardcode credentials or API keys.
- Do not use real patient data in tests; use synthetic fixtures only.

## Required Tests
### Integration Tests
- Create a reminder, wait for notification (1-minute test reminder), verify notification content includes medicine name and prescription date.
- Disable a reminder, verify no notification fires.

### Negative Tests
- A reminder for a deleted medicine does not cause a crash.
