# MHA-033 — Prescription CRUD — backend FastAPI API

## Jira Ticket
- **ID:** MHA-033
- **Epic ID:** MHA-E04
- **Epic Name:** Camera Capture and Document Import
- **Summary:** Prescription CRUD — backend FastAPI API
- **Description:** Implement the FastAPI prescription CRUD endpoints: POST /prescriptions (create), GET /prescriptions (list for authenticated patient), GET /prescriptions/{id} (detail), PATCH /prescriptions/{id} (update metadata), DELETE /prescriptions/{id} (delete with cascade). ## Implementation Boundaries (what NOT to do)
- Do not implement OCR processing on the backend in this ticket — that is a separate backend service concern.
- Do not implement the medicine or alert endpoints — those are later tickets.
- Do not return 403 for cross-patient access — return 404 to avoid leaking resource existence.
- Do not log prescription text, medicine details, or document contents.
- Do not add diagnosis, prescribing logic, dose optimization, or auto-medication changes.
- Do not commit real credentials or API keys.
- Do not refactor unrelated routers.

## Required Tests
### Positive Tests
- Authenticated CRUD operations succeed (create, list, detail, update, delete).

### Security Tests
- Cross-patient access returns 404 (not 403, to avoid leaking resource existence).
- Unauthenticated request returns 401.
- Server log does not contain prescription text after any endpoint call.

### Negative Tests
- Invalid prescription ID returns 404.
- PATCH with invalid fields returns 422.
