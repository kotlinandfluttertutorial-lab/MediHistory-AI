## Required Tests
### Unit Tests
- Search by name and search by ingredient both return correct results (in-memory DB with synthetic data).
- Filter by status returns only medicines with the given `currentStatus`.
- Filter by doctor returns only medicines from that doctor's prescriptions.
- `listByPatient` cannot return another patient's medicines (cross-patient isolation).
- All three `MedicineStatus` values (CURRENT, PAST, UNKNOWN) are independently queryable.

### Security Tests
- `listByPatient` with a different `patientId` returns an empty list.
