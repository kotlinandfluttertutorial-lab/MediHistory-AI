## Required Tests
### Unit Tests
- `getFieldsNeedingReview` returns only fields with `confidenceScore` below the configured threshold.
- Changing the threshold changes the query results.
- `ExtractedField` with `confidenceScore` outside 0.0–1.0 fails `ValidationUtils.isValidConfidence`.
- Source enum resolves OCR and MANUAL values correctly.
- ReviewState enum resolves PENDING_REVIEW, REVIEWED, and REJECTED values correctly.

### Negative Tests
- Confidence score of -0.1 fails validation.
- Confidence score of 1.1 fails validation.
