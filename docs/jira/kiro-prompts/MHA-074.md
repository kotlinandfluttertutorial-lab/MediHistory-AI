# MHA-074 — Audit log — metadata only, no document content

## Jira Ticket
- **ID:** MHA-074
- **Epic ID:** MHA-E11
- **Epic Name:** Security, Privacy, and Data Management
- **Summary:** Audit log — metadata only, no document content
- **Description:** Implement the local audit log: records audit events for share actions, backup attempts, data exports, and account deletion. Each record contains: action type, timestamp, affected entity ID — no prescription text, medicine details, or document content. Audit log is readable by the patient from Settings. Audit log is included in the data export.

## Implementation Boundaries (what NOT to do)
- Do not include prescription text, medicine names, or document content in any audit record.
- Do not transmit audit records to the backend except as part of the full data export (MHA-070).
- Do not implement the share action itself — that is MHA-057.
- Do not implement cloud backup — that is MHA-072.
- Do not bypass the repository pattern or call Room directly from UI.
- Do not hardcode credentials or API keys.
- Do not use real patient data in tests; use synthetic fixtures only.
