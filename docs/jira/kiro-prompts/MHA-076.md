## Required Tests
### Unit Tests — DuplicateDetector:
- Same ingredient, different brand names → one DuplicatePair produced.
- Different ingredients, similar brand names → no DuplicatePair produced.
- Synonym pair (paracetamol / acetaminophen) → treated as the same ingredient.
- Combination product (A+B) vs single ingredient A → reduced-confidence partial match.
- Unreviewed records excluded from detection.
- Same inputs run twice → same output (determinism check).

### Unit Tests — ValidationUtils (all functions, boundary values):
- isValidDate: valid, invalid format, boundary dates.
- isAllowedFileExtension: jpg, jpeg, png, pdf pass; docx, xls, exe fail.
- isValidConfidence: 0.0, 1.0 pass; -0.01, 1.01 fail.
- isValidReviewStateTransition: all allowed transitions pass; invalid transitions fail.
- 100% branch coverage for both classes.
