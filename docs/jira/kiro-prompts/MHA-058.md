## Implementation Boundaries (what NOT to do)
- Do not store prescription text, document content, or medicine details in the audit record — only patientId, documentId, destinationApp, and timestamp.
- Cross-patient access must return 404 (not 403) to avoid leaking resource existence.
- Server logs must not contain documentId contents.
- Do not add diagnosis, prescribing logic, dose optimisation, or auto-medication changes.
- Do not hardcode credentials, API keys, or secrets in any file.
- Do not use real patient data in tests; use synthetic fixtures only.
