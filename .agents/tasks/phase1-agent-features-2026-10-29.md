- [ ] 6. Create `DuplicateExplainerEngine` — pure Kotlin class, no Hilt.

  **New file:** `android/app/src/main/java/com/medihistory/ai/data/duplicate/DuplicateExplainerEngine.kt`

  ```kotlin
  package com.medihistory.ai.data.duplicate

  import com.medihistory.ai.data.model.DuplicateAlert
  import com.medihistory.ai.data.model.MatchType
  import com.medihistory.ai.data.model.Medicine
  import javax.inject.Inject

  /**
   * Generates a plain-language explanation for a duplicate alert pair.
   *
   * Medical safety invariants:
   * - Output ALWAYS uses "potential duplicate" — never "duplicate medication".
   * - Output NEVER uses the words: safe, unsafe, dangerous, stop, harmful, interchangeable.
   * - Output NEVER gives clinical advice or implies a drug combination is safe/unsafe.
   * - The suggested doctor question is informational only.
   * - [explain] is a pure function — no I/O, no side effects.
   *
   * This engine reads only confirmed [Medicine] data (REVIEWED fields via PostReviewProcessor).
   * It never reads raw OCR output.
   */
  class DuplicateExplainerEngine @Inject constructor() {

      /**
       * Generates a plain-language explanation for [alert].
       *
       * @param alert     The duplicate alert entity.
       * @param medicineA The Medicine entity for [DuplicateAlert.medicineAId].
       * @param medicineB The Medicine entity for [DuplicateAlert.medicineBId].
       * @return          A non-blank explanation string. Never null.
       */
      fun explain(
          alert: DuplicateAlert,
          medicineA: Medicine,
          medicineB: Medicine,
      ): String {
          val nameA = medicineA.medicineName
          val nameB = medicineB.medicineName
          val ingredient = alert.matchingIngredient

          val body = when (alert.matchType) {
              MatchType.EXACT -> buildExactExplanation(alert, nameA, nameB, ingredient)
              MatchType.PARTIAL -> buildPartialExplanation(alert, nameA, nameB, ingredient)
          }

          val suggestedQuestion =
              "\n\nSuggested question for your doctor: " +
                  "'Are both $nameA and $nameB still needed, or can one be stopped?'"

          return body + suggestedQuestion
      }

      // -----------------------------------------------------------------------
      // Private helpers
      // -----------------------------------------------------------------------

      private fun buildExactExplanation(
          alert: DuplicateAlert,
          nameA: String,
          nameB: String,
          ingredient: String,
      ): String {
          val doctorPartA = "" // doctor name deliberately omitted — not available at this layer
          val doctorPartB = ""
          // Note: prescribingDoctorId is not passed in to keep the engine pure.
          // Doctor name lookup would require a suspend call; the ViewModel layer
          // handles enrichment if needed in future. For now we omit doctor attribution
          // to keep this a pure, synchronous function per the task spec.
          return "This is a potential duplicate alert. " +
              "Both $nameA and $nameB contain $ingredient as the active ingredient. " +
              "Taking both may increase the total amount of $ingredient you receive. " +
              "Please review this with your doctor or pharmacist before making any changes."
      }

      private fun buildPartialExplanation(
          alert: DuplicateAlert,
          nameA: String,
          nameB: String,
          ingredient: String,
      ): String {
          val combinationContext = if (!alert.combinationNote.isNullOrBlank()) {
              " ${alert.combinationNote}"
          } else {
              " $nameA may be a combination product containing $ingredient."
          }
          return "This is a potential duplicate alert.$combinationContext " +
              "$nameB also contains $ingredient. " +
              "This may result in overlapping amounts of $ingredient. " +
              "Please review this with your doctor or pharmacist before making any changes."
      }
  }
  ```

  **Rationale:** Doctor name lookup requires a suspend/repository call. The task spec says the engine is a pure function. We include the medicine names and ingredient (which are already on the entity/model passed in) and omit doctor attribution — keeping the engine synchronous and side-effect-free. The ViewModel layer can enrich if required later.

- [ ] 9. Create `OcrCorrectionEngine` — pure Kotlin class, no Hilt.

  **New file:** `android/app/src/main/java/com/medihistory/ai/data/ocr/OcrCorrectionEngine.kt`

  ```kotlin
  package com.medihistory.ai.data.ocr

  import com.medihistory.ai.data.model.Doctor
  import com.medihistory.ai.data.model.ExtractedFieldEntity
  import java.time.LocalDate
  import java.time.format.DateTimeFormatter
  import java.time.format.DateTimeParseException
  import javax.inject.Inject

  /**
   * Suggests corrections for low-confidence OCR fields.
   *
   * Medical safety invariants:
   * - NEVER suggests a value for dose, frequency, or any clinical field.
   * - Returns null for any field not explicitly handled below.
   * - Suggestions are derived directly from [rawValue] — nothing is fabricated.
   * - The patient MUST confirm every suggestion before it is applied.
   *
   * Privacy: field values must never be logged inside this class.
   *
   * This is a pure, synchronous class. Doctor lookup is passed in as a parameter
   * so callers (ViewModels) can resolve the list asynchronously before calling.
   */
  class OcrCorrectionEngine @Inject constructor() {

      /**
       * Returns a suggested corrected value for [fieldName] with [rawValue], or null if
       * no confident suggestion can be derived.
       *
       * @param fieldName   The OCR field key (e.g. "doctor_name", "prescription_date").
       * @param rawValue    The raw OCR string for this field. May be blank.
       * @param allFields   All extracted fields for the same prescription (for context).
       * @param knownDoctors The patient's known doctors — used for fuzzy name matching.
       */
      fun suggest(
          fieldName: String,
          rawValue: String,
          allFields: List<ExtractedFieldEntity>,
          knownDoctors: List<Doctor> = emptyList(),
      ): String? {
          if (rawValue.isBlank()) return null

          return when {
              fieldName == "doctor_name" -> suggestDoctorName(rawValue, knownDoctors)
              fieldName == "prescription_date" -> suggestDate(rawValue)
              fieldName == "medicine_name" ||
                  fieldName.startsWith("medicine_name_") -> suggestMedicineName(rawValue)

              // NEVER suggest for clinical fields — return null unconditionally.
              fieldName.startsWith("dose") ||
                  fieldName.startsWith("frequency") ||
                  fieldName == "diagnosis" ||
                  fieldName == "allergy" -> null

              else -> null
          }
      }

      // -----------------------------------------------------------------------
      // Field-specific suggestion logic
      // -----------------------------------------------------------------------

      /**
       * Cleans OCR artefacts from a doctor name and fuzzy-matches against known doctors.
       * Returns the best Levenshtein ≤ 2 match from [knownDoctors], or the cleaned raw
       * value if no match exists but cleaning produced a change.
       */
      private fun suggestDoctorName(rawValue: String, knownDoctors: List<Doctor>): String? {
          val cleaned = rawValue
              .replace(Regex("[|\\\\@#$%^&*<>{}\\[\\]]"), "")  // strip common OCR symbol artefacts
              .replace(Regex("\\s+"), " ")
              .trim()

          if (cleaned == rawValue.trim()) {
              // No cleaning improvement — only return if a doctor name matches
              val match = knownDoctors.minByOrNull { levenshtein(cleaned, it.name) }
              return if (match != null && levenshtein(cleaned, match.name) in 1..2) match.name
              else null
          }

          // Cleaning improved the value — check doctor match first, then return cleaned
          val match = knownDoctors.minByOrNull { levenshtein(cleaned, it.name) }
          return if (match != null && levenshtein(cleaned, match.name) <= 2) match.name
          else cleaned.takeIf { it != rawValue.trim() }
      }

      /**
       * Tries the same 7 date formats as [PostReviewProcessor.parseDate] and returns
       * an ISO-formatted date if any format succeeds.
       */
      private fun suggestDate(rawValue: String): String? {
          val formats = listOf(
              DateTimeFormatter.ISO_LOCAL_DATE,
              DateTimeFormatter.ofPattern("dd/MM/yyyy"),
              DateTimeFormatter.ofPattern("dd-MM-yyyy"),
              DateTimeFormatter.ofPattern("d MMM yyyy"),
              DateTimeFormatter.ofPattern("dd MMM yyyy"),
              DateTimeFormatter.ofPattern("MMMM d, yyyy"),
              DateTimeFormatter.ofPattern("d/M/yyyy"),
          )
          val parsed = formats.firstNotNullOfOrNull { fmt ->
              try { LocalDate.parse(rawValue.trim(), fmt) } catch (_: DateTimeParseException) { null }
          } ?: return null

          // Return ISO format only if it differs from the raw input
          val iso = parsed.format(DateTimeFormatter.ISO_LOCAL_DATE)
          return if (iso != rawValue.trim()) iso else null
      }

      /**
       * Strips trailing punctuation and normalises spacing in a medicine name.
       * Returns null if the cleaned value equals the raw input.
       */
      private fun suggestMedicineName(rawValue: String): String? {
          val cleaned = rawValue
              .trimEnd('.', ',', ';', ':', '-')
              .replace(Regex("\\s+"), " ")
              .trim()
          return if (cleaned != rawValue.trim()) cleaned else null
      }

      // -----------------------------------------------------------------------
      // Levenshtein distance — simple iterative implementation
      // -----------------------------------------------------------------------

      internal fun levenshtein(a: String, b: String): Int {
          val aLower = a.lowercase()
          val bLower = b.lowercase()
          val dp = Array(aLower.length + 1) { IntArray(bLower.length + 1) }
          for (i in 0..aLower.length) dp[i][0] = i
          for (j in 0..bLower.length) dp[0][j] = j
          for (i in 1..aLower.length) {
              for (j in 1..bLower.length) {
                  val cost = if (aLower[i - 1] == bLower[j - 1]) 0 else 1
                  dp[i][j] = minOf(dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + cost)
              }
          }
          return dp[aLower.length][bLower.length]
      }
  }
  ```

- [ ] 14. Create `ReminderAdvisorEngine` — pure Kotlin class, no Hilt.

  **New file:** `android/app/src/main/java/com/medihistory/ai/data/reminders/ReminderAdvisorEngine.kt`

  ```kotlin
  package com.medihistory.ai.data.reminders

  import java.time.LocalTime
  import javax.inject.Inject

  /**
   * Suggests reminder times based on confirmed dosage instructions.
   *
   * Medical safety invariants:
   * - Returns null when instructions are null, blank, or match no known pattern.
   * - NEVER guesses or fabricates a time.
   * - Output is presented as a suggestion only — the patient confirms all times.
   * - The disclaimer "confirm timing with your doctor or pharmacist" is shown in the UI.
   *
   * Privacy: dosage instructions are never logged inside this class.
   *
   * This is a pure, synchronous function. It reads only the dosage string.
   */
  class ReminderAdvisorEngine @Inject constructor() {

      /**
       * Parses [dosageInstructions] and returns suggested reminder times.
       *
       * @param dosageInstructions The confirmed [Medicine.dosageInstructions] string.
       * @return [ReminderSuggestion] with times and a human-readable explanation,
       *         or null when no pattern is matched.
       */
      fun suggest(dosageInstructions: String?): ReminderSuggestion? {
          if (dosageInstructions.isNullOrBlank()) return null
          val lower = dosageInstructions.lowercase().trim()

          // ── Frequency detection ────────────────────────────────────────
          val baseTimes: List<LocalTime> = when {
              matchesOnceDaily(lower) -> listOf(LocalTime.of(8, 0))
              matchesTwiceDaily(lower) -> listOf(LocalTime.of(8, 0), LocalTime.of(20, 0))
              matchesThreeTimesDaily(lower) ->
                  listOf(LocalTime.of(8, 0), LocalTime.of(14, 0), LocalTime.of(20, 0))
              matchesBedtime(lower) -> listOf(LocalTime.of(21, 0))
              else -> return null   // no pattern matched — never guess
          }

          // ── Meal modifier detection ────────────────────────────────────
          val times = when {
              lower.contains("after meal") || lower.contains("after food") ||
                  lower.contains("pc") || lower.contains("post meal") ->
                  afterMealTimes(baseTimes)

              lower.contains("before meal") || lower.contains("before food") ||
                  lower.contains("ac") || lower.contains("pre meal") ->
                  beforeMealTimes(baseTimes)

              else -> baseTimes
          }

          val explanation = buildExplanation(dosageInstructions, times)
          return ReminderSuggestion(times = times, explanation = explanation)
      }

      // -----------------------------------------------------------------------
      // Pattern matchers
      // -----------------------------------------------------------------------

      private fun matchesOnceDaily(s: String) =
          s.contains("once daily") || s.contains("once a day") ||
              s.contains("\\bod\\b".toRegex()) || s.contains("1-0-0") ||
              (s.contains("morning") && !matchesTwiceDaily(s) && !matchesThreeTimesDaily(s))

      private fun matchesTwiceDaily(s: String) =
          s.contains("twice daily") || s.contains("twice a day") ||
              s.contains("\\bbd\\b".toRegex()) || s.contains("\\bbid\\b".toRegex()) ||
              s.contains("1-0-1") || s.contains("1-1-0")

      private fun matchesThreeTimesDaily(s: String) =
          s.contains("three times daily") || s.contains("three times a day") ||
              s.contains("\\btds\\b".toRegex()) || s.contains("\\btid\\b".toRegex()) ||
              s.contains("1-1-1")

      private fun matchesBedtime(s: String) =
          s.contains("at bedtime") || s.contains("\\bhs\\b".toRegex()) ||
              s.contains("\\bnightly\\b".toRegex()) || s.contains("0-0-1") ||
              (s.contains("night") && !matchesTwiceDaily(s) && !matchesThreeTimesDaily(s))

      // -----------------------------------------------------------------------
      // Meal-time adjustments
      // -----------------------------------------------------------------------

      /** Shifts base times to post-meal: 08:30, 13:30, 20:30 */
      private fun afterMealTimes(base: List<LocalTime>): List<LocalTime> {
          val postMeal = listOf(
              LocalTime.of(8, 30),
              LocalTime.of(13, 30),
              LocalTime.of(20, 30),
          )
          return base.mapIndexed { i, _ -> postMeal.getOrElse(i) { base[i] } }
      }

      /** Shifts base times to pre-meal: 07:45, 13:00, 20:00 */
      private fun beforeMealTimes(base: List<LocalTime>): List<LocalTime> {
          val preMeal = listOf(
              LocalTime.of(7, 45),
              LocalTime.of(13, 0),
              LocalTime.of(20, 0),
          )
          return base.mapIndexed { i, _ -> preMeal.getOrElse(i) { base[i] } }
      }

      // -----------------------------------------------------------------------
      // Explanation builder
      // -----------------------------------------------------------------------

      private fun buildExplanation(instructions: String, times: List<LocalTime>): String {
          val timeStrings = times.joinToString(" and ") { t ->
              val hour = if (t.hour == 0) 12 else if (t.hour > 12) t.hour - 12 else t.hour
              val amPm = if (t.hour < 12) "AM" else "PM"
              val min = if (t.minute == 0) "" else ":${t.minute.toString().padStart(2, '0')}"
              "$hour$min $amPm"
          }
          return "Based on \"$instructions\" → $timeStrings"
      }
  }

  /**
   * The output of [ReminderAdvisorEngine.suggest].
   *
   * @param times       The suggested reminder times. Never empty when non-null.
   * @param explanation A human-readable description of how the times were derived.
   */
  data class ReminderSuggestion(
      val times: List<LocalTime>,
      val explanation: String,
  )
  ```

## Assumptions and Flags

1. **Doctor name in EXACT explanation omitted:** The task spec says `"prescribed by [doctorA]"` but `DuplicateExplainerEngine.explain()` is a pure synchronous function with no repository access. Passing doctor names would require either a suspend call or pre-fetching. The plan keeps the engine pure and omits doctor attribution in the body; the suggested question still names both medicines. The ViewModel layer (or a future richer overload) can supply doctor names if required.

2. **`TimeInput` vs full `TimePicker` in `ReminderAdvisorDialog`:** Material 3's `TimeInput` (text-based) and `TimePicker` (clock dial) both require `@ExperimentalMaterial3Api`. The plan uses text labels with a stub `TextButton` for time display and a TODO comment for the time picker dialog, matching the scope of this plan and avoiding a nested `AlertDialog` inside another `AlertDialog` (which has layout issues on older API levels). The full inline clock picker can be implemented as a follow-up when the dialog is extracted to its own full-screen dialog.

3. **`ExtractedFieldEntity` import in `OcrCorrectionEngine`:** The engine receives `List<ExtractedFieldEntity>` for context. This list is only used for possible cross-field context (currently unused in the implementations above, but the parameter is on the signature as specified). The correct import is `com.medihistory.ai.data.model.ExtractedFieldEntity` (confirmed from source).

4. **`PostReviewProcessorInterface` vs `PostReviewProcessor`:** The DI graph binds the interface to the concrete class via `@Binds @Singleton` in `android/app/src/main/java/com/medihistory/ai/data/di/OcrDaoModule.kt`. The constructor change in step 7a adds `DuplicateExplainerEngine` to `PostReviewProcessor` (the concrete class). `OcrDaoModule` does **not** need to change — Hilt will automatically inject `DuplicateExplainerEngine` into the constructor because it has `@Inject constructor()`. The interface is also unchanged.

5. **`mutableStateListOf` in `ReminderAdvisorDialog`:** This is `androidx.compose.runtime.mutableStateListOf` — it enables the advisor dialog's time list to be observed by Compose during editing. Confirm the import path at compile time.
